# Archived Design Docs

This directory contains superseded or historical design materials that are no longer the active basis for implementation.

## Buckets

- `completed-implementation-history/` — completed TODO breakdowns and historical implementation plans
- `superseded-pre-streamable-reset/` — designs that assumed dual-path, REST, stdio, or HTTP/SSE sampling as active directions

These files remain useful as historical reference, but should not be used as the current source of truth.
